Input image 1 is a visual reference of the storyboard screen, NOT an edit target or output layout. Recreate ONLY its corresponding illustration as a crisp standalone asset. Subject: {subject} Style: soft pastel rounded 3D/clay-render illustration, gentle studio lighting, subtle shading, violet #5030E5 and pale lavender, preserve the reference composition and object proportions as closely as possible. Composition: centered complete illustration, tightly framed with about 6% empty margin, no clipped objects. Background: genuinely transparent. Avoid: any UI, phone, buttons, headings, words, letters, logos, watermark, border, harsh shadows, new objects. Code-symbol glyphs </> are permitted only on coding objects. Output one standalone illustration.
