# 문법 화면 구현 범위

## 1. 문법 홈 (`/grammar`)

- 홈 하단의 `문법` 또는 학습 이력이 없는 홈의 `학습 시작하기`로 진입합니다.
- 홈 메뉴는 `홈 / 문법 / 실무 / 문제 / 챗봇`으로 구분합니다.
  `실무`는 화면 구현 전까지 준비 중 안내를 표시합니다.
- Java / Python / JavaScript 선택, 제목·설명 검색, 오늘 학습 진행률을 표시합니다.
- 검색 결과가 없으면 안내하고 검색어를 지울 수 있습니다.
- COBIP 상단 바와 하단 메뉴를 유지하며 `문법` 메뉴를 선택 상태로 표시합니다.
- 제목과 소개는 `문법 학습`, `코드를 더 잘 이해하는 시작`, `COBIP와 함께 문법을 학습해보세요` 순서로 표시합니다.
- 문법 홈의 챗봇은 하단 메뉴에서 열고 원형 버튼은 챕터 화면부터 표시합니다.
- 챗봇은 준비 안내만 제공하며 닫으면 검색·언어 선택을 유지합니다.
- 하단 `홈`을 누르면 홈으로 복귀합니다. 직접 경로로 진입해도 홈으로 돌아갑니다.

## 2. 챕터 목록 (`/grammar/:language/chapters`)

- 문법 홈의 `전체 보기`는 선택한 언어의 전체 목록으로 이동합니다.
- 문법 홈의 챕터 카드는 해당 언어·카테고리의 목록으로 이동합니다.
- 전체 / 기초 / 제어문 / 객체지향 / 컬렉션 필터로 목록을 바꿉니다.
- 각 카드에 제목, 설명, 학습 중·완료·미시작 상태와 진행률을 표시합니다.
- 조건문 카드만 상세 진입이 가능하며 다른 챕터는 목록 확인만 가능합니다.
- 뒤로 돌아오면 문법 홈의 검색어·언어 선택을 유지합니다.
- 잘못된 언어 경로는 문법 홈으로 복귀하고 잘못된 카테고리는 전체 목록으로 처리합니다.
- 챕터 화면에 진입하면 하단 바를 숨기고 뒤로가기와 챗봇 원형 버튼을 표시합니다.

## 임시 데이터

`lib/features/grammar/data/grammar_sample_data.dart`에 언어별 챕터와 예시 진행률을 모았습니다.
앱을 재실행하면 예시 상태로 시작하며 서버 호출·영구 저장은 하지 않습니다.
언어별 문법 내용은 구분하되 오늘 학습 수치는 공통 예시입니다.

## 다음 작업

조건문 외 문법 개념·예제, 퀴즈·결과와 실제 챗봇 대화는 후속 작업 범위입니다.
실무·문제·마이페이지 등 다른 담당 영역은 이번 변경에 포함하지 않습니다.

## 확인 결과

- Flutter 3.47.5 / Dart 3.13.4에서 정적 분석과 테스트 11개를 통과했습니다.
- 홈 진입, 언어별 검색, 검색 결과 없음, 챕터 카테고리 필터, 뒤로가기 상태 유지,
  잘못된 경로 복귀와 챗봇 안내 패널의 닫기를 확인했습니다.
- `screenshots/grammar-home.png`, `screenshots/grammar-chapters.png`는
  390×844 크기의 위젯 렌더링 이미지입니다. 검토용 한글 폰트는 맑은 고딕을 사용했으며
  Android 기기의 실제 글꼴 및 시스템 영역과 차이가 있습니다.
- 실제 Android 기기 실행은 아직 확인하지 않았습니다.

## 3. 조건문 개념 (`/grammar/:language/chapters/conditions`)

- 제어문 카테고리의 조건문 카드에서 진입합니다.
- 핵심 개념, 조건별 분기 설명, 간단한 코드 예시를 표시합니다.
- `이전`은 목록으로, `예제 보기`는 예제 코드 페이지로 이동합니다.
- 상단의 `1 / 1`은 이번 임시 데이터에 포함된 개념 하나의 위치이며 학습 완료율이 아닙니다.

## 4. 조건문 예제 (`/grammar/:language/chapters/conditions/example`)

- 줄 번호가 있는 코드, 단계별 실행 흐름, 예상 출력 `합격`을 표시합니다.
- 코드 영역은 가로 스크롤·텍스트 선택이 가능하며 실제 실행 기능은 없습니다.
- `개념 다시 보기`는 개념 페이지로 복귀합니다. 퀴즈는 아직 구현하지 않아 비활성 상태입니다.
- 두 상세 페이지는 하단 메뉴 없이 고정 이동 버튼과 원형 챗봇 안내 버튼을 제공합니다.
- Java / Python / JavaScript별 예제는 `data/condition_lesson_data.dart`에서 관리합니다.

- 상세 화면 검토 이미지는 `screenshots/grammar-concept.png`, `screenshots/grammar-example.png`에 기록합니다.
