# 메인 API 연동 작업 기록

## 범위와 기준

- 작업일: 2026-10-10, 기준 develop: `383e8ee0353a38131cc493f7bf150d0ed5061ea2`.
- 작업 브랜치: `feat/home-api-integration`, PR base: `develop`.
- PR #12에 통합된 인증 코어를 재사용합니다. 메인 화면과 전용 API·ViewModel·회귀 테스트·문서만 변경합니다.
- 다른 팀원의 문법·실무·문제·챗봇·마이페이지, 공통 하단바·라우터·UI 토큰, 백엔드 계약·DB 스키마와 의존성은 변경하지 않습니다.

## 이미 제공된 API 연결

| API | 메인에서 사용하는 역할 |
| --- | --- |
| `GET /api/templates?publishedOnly=true` | 공개 학습 제목·설명·카테고리·언어를 서버 표시 순서로 표시 |
| `GET /api/users/{userId}/progress/templates/{templateId}` | 로그인한 본인의 템플릿별 기록을 읽고 `lastStudiedAt`이 가장 최근인 항목 선택 |

`HomeApi`는 `AuthViewModel.api.dio`를 그대로 사용합니다. Bearer 첨부, 만료 시 토큰 갱신 및 401 한 번 재시도는 기존 인증 인터셉터가 처리합니다. 새 주소·인증 방식은 추가하지 않습니다.

서버 응답의 타입·양의 식별자·시간대가 있는 날짜를 확인하며, 진도 응답의 사용자·템플릿 ID가 요청과 다르면 오류로 처리합니다. 진도 404만 미시작으로 해석하고, 목록 오류 또는 다른 진도 조회 실패를 빈 데이터로 숨기지 않습니다.

## 화면 상태와 동작

- 로딩, 등록된 학습 없음, 학습 목록은 있지만 개인 기록 없음, 정상 기록, 오류·재시도를 구분합니다.
- 등록된 학습 목록과 최근 공개 학습의 진행 중/완료 상태·마지막 섹션 ID·학습 날짜를 표시합니다.
- 새로고침과 아래로 당겨 갱신은 실제 API를 다시 호출합니다. 진행 중 중복 요청을 제한합니다.
- 사용자 ID가 바뀌면 화면 범위 ViewModel을 새로 만들며, 종료된 모델의 늦은 응답을 화면에 반영하지 않습니다.
- 샘플 제목·350ms 모의 성공·고정 33%·Python 예제 강제 이동을 제거합니다.

## 남은 계약·다른 팀 작업 경계

- 현재 API에는 계정 전체의 최근 학습 조회가 없습니다. 공개 템플릿 목록에 대해 `1+N` 요청을 최대 4개씩 실행합니다. 표시하는 최근 기록은 **현재 공개 목록 내 최근 기록**이며 비공개 콘텐츠를 포함한 계정 전체 최근 기록이 아닙니다. 집계 API가 제공되면 대체할 필요가 있습니다.
- `lastSectionId`는 완료 단계 수가 아닙니다. 진도 응답에 완료 단계 수·전체 단계 수가 없으므로 퍼센트를 추정하지 않습니다.
- 서버 추천 순위는 제공되지 않습니다. 기존 추천 영역에는 공개 목록을 서버의 `displayOrder`/ID 순서 그대로 표시하며 별도 추천 알고리즘을 만들지 않습니다.
- 기존 학습 상세 경로는 서버 `templateId`·`sectionId`를 받지 않습니다. 다른 팀 화면을 수정하거나 임의 샘플로 이동시키지 않고 카드에 상세 연결 준비 중 안내를 제공합니다. **실제 학습 상세 열기·특정 섹션 이어하기는 이 PR에 포함되지 않습니다.**
- 백엔드의 교차 계정 북마크 조회 권한 문제는 앞선 로컬 검사에서 확인된 별도 문제입니다. 프론트에서 다른 사용자 ID를 조회하지 않지만 이것이 백엔드 권한 오류의 수정은 아닙니다.

### 실제 로컬 서버와 테스트 데이터의 구분

- 격리된 로컬 서버 `127.0.0.1:18080`와 Mailpit `127.0.0.1:18025`에 실제 Dio 요청을 보냈습니다. 임시 캡처 하네스의 최종 실행 2개 테스트가 통과했습니다.
- 개발용 메일 인증·회원가입·로그인 후 `HomeScreen`의 공유 Dio가 실제 공개 목록을 조회하고, 현재 서버의 정상 빈 응답을 빈 화면으로 표시하는 것을 확인했습니다. 이후 서버 로그아웃을 호출했습니다. 생성한 테스트 계정·메일은 격리된 검증 환경에 남아 있습니다.
- 이 검증은 **메모리 토큰 저장소**를 사용한 위젯 하네스입니다. Android 보안 저장소·앱 재시작·실기기·운영 SMTP 검증이 아닙니다. 비밀값과 하네스·로그는 커밋하지 않습니다.
- 현재 로컬 서버에 학습 콘텐츠가 없으므로 **실제 콘텐츠가 있는 목록·개인 진도 조회는 이번 실행에서 미검증**입니다. 해당 DTO·진도 동작은 자동 테스트의 adapter 응답으로 확인했습니다.
- CI는 PR의 최종 head에서 별도로 확인합니다. 현재 저장소 CI는 의존성·포맷·분석·debug APK를 검사하며, 전체 Flutter 테스트는 위의 로컬 실행 결과입니다.
