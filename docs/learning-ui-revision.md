# 학습 화면 디자인 정리

기준 브랜치: develop `80bf6a9` / 작업 브랜치: `feature/learning-ui-revision`

사용자가 제공한 COBIA Flutter UI 기준과 기존 인증·홈의 `app_ui_tokens.dart`를 참고했다. 문법, 실무, 문제, 챗봇에만 별도 테마를 적용한다.

## 화면별 변경

- 문법: 제목과 안내 문구의 위계, 진행률 카드, 언어 선택 칩, 챕터 카드, 개념·예제·퀴즈 카드 및 하단 버튼 스타일 통일.
- 실무: 흰색 주제 카드에 아이콘·분류·태그·챕터 수를 정돈하고 상세 코드 영역에 줄 번호 추가.
- 문제: 목록·답안 입력·선택지·결과 카드의 색상과 간격 통일. 정답은 기존처럼 얇은 초록 테두리로 표시.
- 챗봇: 전체 페이지와 하단 패널에 같은 말풍선·입력창·전송 버튼 스타일 적용.
- 공통: 기존 보라색 토큰, 16px 카드 모서리, 16/20px 바깥 여백, 최대 본문 너비 560px, 56px 챗봇 버튼 사용. 표시 브랜드는 COBIA로 통일.

## 유지한 동작

화면 경로, 하단 바 노출 조건, 검색·언어 선택, 챕터 이동, 퀴즈 제출, 문제 채점·오답 재풀이, 챗봇 대화·초안 유지 로직은 변경하지 않았다. 제공 문서에 있는 학습 전체 하단 바 숨김이나 페이지 이동 시 채팅 초기화 같은 기능 제안은 이번 디자인 작업에 포함하지 않았다. 더미 학습 내용과 채점 데이터도 유지했다.

## 검증

- Flutter 3.47.5 / Dart 3.13.4 사용.
- `flutter analyze --no-pub`: 통과.
- `flutter build apk --debug --no-pub`: 통과.
- 전체 테스트: 변경 전 75개 통과 / 7개 실패 → 변경 후 81개 통과 / 같은 7개 실패.
- 기존 실패: `grammar_chapters_test.dart`의 6개 이동 검사와 `grammar_quiz_test.dart`의 결과 후 챕터 수 검사. 기존 develop의 전체 챕터 표시 변경과 관련되어 이번 디자인 범위에서 수정하지 않았다.
- 추가 레이아웃 검사: 360×800, 320×640(글자 200%), 800×600에서 11개 경로, 문법 하단 버튼 위치와 챗봇 키보드 표시 확인.
- 기존 기능 테스트의 표시 브랜드를 갱신하고 스크롤 후 레이아웃 완료를 기다리도록 보완했다. 기존 검증 조건은 유지했다.

## 검토 이미지

### 전체 화면 구성

이전 인증·홈 PR(#7)의 `home_learning`, `login_code`, `terms_robot`, `sign_up_complete` 일러스트를 재사용했다. 학습 소개와 결과의 대표 영역만 강조하고 일반 학습 카드는 기준에 맞춰 흰색·16px 모서리·1px 테두리·약한 그림자로 정리했다. 반복 그라데이션과 카드 상단 장식 선은 제거했다.

- 문법: 홈, 챕터 목록, 개념, 예제, 퀴즈, 결과 전체에 적용. 단계 패널, 구분된 본문 카드 헤더, 코드 프레임, 결과 일러스트를 사용한다.
- 실무: 주제 목록, 챕터 목록, 상세 전체에 적용. 대표 소개, 주제 아이콘, 번호 배지와 본문 섹션을 통일했다.
- 문제: 목록, 입력, 결과 전체에 적용. 문제 유형별 헤더와 코드 영역, 결과 요약과 더미 채점 안내를 분리했다. 정답의 얇은 초록 테두리는 유지한다.
- 챗봇: 첫 화면의 로봇 일러스트·정적 예시 질문, AI 아바타·말풍선, 입력창·전송 버튼을 전체 페이지와 시트에서 공유한다. 예시 질문은 새 기능 버튼이 아닌 안내 문구다. 대화 전에는 소개 상단을 보여주고 메시지 전송 후에는 기존처럼 마지막 답변으로 스크롤한다. 가로 키보드로 높이가 부족하면 학습 복귀 버튼을 헤더에 배치한다.

추가 검사: 챗봇 시트의 360×800, 320×640(200%), 640×320 가로 키보드와 문법·문제 결과 화면을 검사했다. 문법/실무/문제 데이터, 라우터, 채점 및 챗봇 ViewModel에는 변경이 없다.

`docs/screenshots/learning-ui-revision/`에 모든 화면과 챗봇 첫 화면, 문법 퀴즈·결과, 320×640(200%) 이미지를 저장했다. 기본 이미지는 360×800 위젯 렌더링이며 실제 Android 캡처는 아니다. 검토 시 한글 글꼴을 주입했으므로 실제 기기와 줄바꿈에 차이가 있을 수 있다.

`chat-android.png`는 최신 APK를 Pixel 9 Pro 에뮬레이터에 설치하고 로그인 후 챗봇 탭에서 직접 캡처한 실제 Android 화면이다.
