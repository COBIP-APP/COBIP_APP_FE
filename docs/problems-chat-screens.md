## 2026-10-12 학습 카드별 챗봇 대화 분리

문법·실무 상세는 DB의 `templateId`별 대화를 사용한다. 예를 들어 Python 조건문, Python 반복문, Java 조건문, 실무 캐시 카드는 서로 다른 대화다. 카드 이름·언어 이름·목차 제목을 키로 사용하지 않으므로 이름이 같아도 섞이지 않는다. 같은 학습 카드 안에서는 목차를 이동하거나 쿼리의 section을 바꿔도 대화가 이어진다.

- 메인 `/chat`은 `main`, 학습 카드는 `template:{templateId}`로 나눈다. 카드 ID가 없는 기존 목록의 챗봇 진입은 메인 대화를 사용한다. 문제 풀이 화면의 챗봇 제거 상태는 유지한다.
- 앱 범위의 `ChatSessions`가 각 대화의 `ChatViewModel`을 보관한다. 패널을 닫거나 다른 페이지로 이동해도 메시지, 입력 초안, 로딩, 오류, 재시도 대상이 해당 대화에 남는다.
- 요청 중 다른 카드로 이동해도 응답은 요청을 시작한 카드에만 반영한다. 중복 전송 잠금은 대화마다 적용하므로 다른 카드의 요청이 끝나기를 기다릴 필요는 없다.
- 학습 패널 제목에 카드 이름을 표시한다. 기존 색상·글꼴·바텀시트·말풍선 배치를 유지한다.
- 로그아웃·계정 변경·인증 세션 해제 시 모든 대화와 입력 초안을 초기화하고 진행 중인 요청을 취소한다. 열린 입력창도 초기화한다. 챗봇이 닫혀 있을 때도 인증 변경을 구독한다. 같은 계정의 토큰 갱신에는 대화를 유지한다.
- 메모리에만 저장한다. 앱 프로세스 종료 후 다시 실행하면 초기 상태이며 파일·DB·기기 저장소에는 기록하지 않는다. 앱이 백그라운드로 이동해도 프로세스가 유지되면 대화는 남는다.
- 이번 변경은 FE의 대화 표시·상태 분리다. 기존 AI 호출 경로와 요청 본문은 바꾸지 않으며, 카드 내용이나 이전 대화를 AI에 자동 전달하지 않는다. 서버 대화방·대화 저장 API도 추가하지 않는다.

핵심 파일: `chat_sessions.dart`(대화 보관·인증 초기화), `chat_panel.dart`(대화별 화면 연결), `learning_detail_scaffold.dart` / `template_preview_screen.dart`(학습 카드 ID 전달), `cobip_app.dart`(앱 범위 보관).

테스트: `test/chat_sessions_test.dart`에서 카드별 동시 요청과 늦은 응답, 재시도 분리, 로그아웃/동일 계정 재로그인, 문법·실무·메인 화면 왕복, 같은 카드의 목차 이동, 동일 제목/다른 언어 카드, 초안 복원을 검증한다. 기존 학습 레이아웃 테스트로 작은 화면·큰 글씨·키보드 상태도 확인한다.

검증 결과: 정적 분석 문제 없음, 전체 테스트 212개 통과, 로컬 BE 주소를 사용한 Android debug APK 빌드 성공. AI 요청은 테스트 서버 응답으로 검증했으며 이번 변경으로 운영 AI에 추가 요청을 보내거나 BE·DB를 수정하지 않았다.

아래는 초기 화면 구현 기록이다. 현재 학습·문제 API 연결 및 저장 기능은 [학습 API 변경 기록](learning-api-preview.md)을 참고한다.

# 문제 풀이와 챗봇 패널

최신 develop의 실무·마이페이지 병합 내용에서 `feature/problems-chat-panel`을 생성했습니다.

| 화면 | 파일 | 동작 |
| --- | --- | --- |
| 문제 목록 | `lib/features/problems/presentation/problems_home_screen.dart` | Java·Python·JavaScript 미션 선택, 문제 탭 표시, 프로필 이동 |
| 미션 풀이 | `lib/features/problems/presentation/problem_mission_screen.dart` | 코드 작성, 객관식 선택, 출력값 입력을 스크롤로 확인 |
| 풀이 결과 | `lib/features/problems/presentation/problem_result_screen.dart` | 정오답 표시, 선택해서 펼치는 정답·풀이, 문제 목록 복귀 |
| 공통 챗봇 패널 | `lib/features/chat/presentation/chat_panel.dart` | 현재 화면 위에 채팅 영역 표시, 입력·전송·닫기 |

## 문제 데이터와 범위

- `data/problem_sample_data.dart`에 언어별 3문항씩 총 9문항의 더미 데이터를 분리했습니다.
- 경로는 `/problems`와 `/problems/:mission`이며 잘못된 미션은 목록으로 돌아갑니다.
- 세 답안을 모두 입력한 뒤 채점하기를 누르면 결과 확인 화면을 표시합니다. 코드 입력은 공백만 입력하면 제출할 수 없습니다.
- 세 문항 모두 더미 정답으로 임시 판정합니다. 코드는 실행하지 않고 예시 코드와 문자열을 비교합니다(CRLF 정규화 및 앞뒤 공백 제거). 같은 동작의 다른 코드도 오답으로 표시될 수 있으며 이 제한을 화면에 안내합니다.
- 세 문항이 모두 정답이면 문제 목록 복귀 버튼만 표시합니다. 오답이 있으면 다시 풀기와 나가기 버튼을 제공합니다.
- 다시 풀기는 틀린 코드·객관식·출력값 문항만 답을 초기화해 보여줍니다. 이미 맞힌 답은 유지하며, 재제출 후에도 남은 오답만 반복해서 풀 수 있습니다. 정답과 풀이는 결과 카드에서 별도 버튼을 눌러야 표시됩니다.
- 완료 표시, 학습 진도, 서버 저장을 갱신하지 않습니다. 미션을 나가면 입력은 유지하지 않습니다.
- 상세·결과는 하단 메뉴를 숨기고 원형 챗봇 버튼을 제공합니다.

## 챗봇 동작

- 하단 챗봇 메뉴는 `/chat` 전용 페이지로 이동하며 챗봇 탭을 선택 표시합니다. 뒤로가기로 이전 화면에 복귀합니다.
- 학습·문제 상세의 우측 하단 원형 버튼은 기존 바텀시트 패널을 엽니다. 전용 페이지와 패널은 동일한 대화·임시 입력 데이터를 공유합니다.
- 닫기 버튼, 학습 계속하기, 바깥 영역 터치 등으로 닫아도 기존 화면의 답안과 위치를 유지합니다.
- Provider + ChangeNotifier로 앱 실행 중 대화와 입력 중인 메시지를 공유합니다. 파일·서버에 저장하지 않습니다.
- 응답은 `data/chat_sample_data.dart`의 키워드 기반 샘플입니다. AI 연결, 코드 분석, 자동 문제 맥락 전달은 없습니다.
- 패널에 더미 응답임을 표시합니다. 공백 메시지는 보낼 수 없고 입력은 1,000자로 제한합니다.
- 키보드 높이만큼 패널을 조정하며 대화 목록은 스크롤할 수 있습니다.
